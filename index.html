Map app

Yogyakarta Parking Map

A map that shows parking zones in Yogyakarta and works out the fee for you. If your point sits outside the data, it says so instead of guessing.

  • FastAPI
  • PostGIS
  • MapLibre
Satellite data

Kalimantan Fire Maps

Daily fire dots from satellites, grouped into whole events. The maps show where a fire started, where it went, and which land burns again and again.

  • Python
  • GeoPandas
  • Matplotlib
Map analysis

Fish Landing Sites, Natuna

A map that scores each possible fish landing site. It weighs water depth, shelter from waves, roads, and how many people live nearby.

  • QGIS
  • GDAL
  • Rasterio

How I work

Just three steps

01

Ask first

I start with one thing: what do you need to decide, and what data do you already have.

02

Build and check

Built bit by bit and tested with real data. Every number can be traced back to where it came from.

03

Hand it over

You get the code and the notes, so somebody else can run it again without me.
